# solar panel dust monitor System 
Dust accumulation can reduce the light reaching solar panels and affect their performance, while frequent manual inspections are time-consuming, especially across large installations. This project uses an Arduino Uno and LDR sensor to compare a monitored panel’s light level with a clean-panel reference. Based on the difference, it identifies the panel’s dust condition and displays a status message on a 16×2 LCD connected through a PCF8574 I²C module. Red, yellow, and green LEDs provide additional condition indicators. Future development could apply linear regression to readings from multiple panels to predict cleaning needs and support maintenance planning.
